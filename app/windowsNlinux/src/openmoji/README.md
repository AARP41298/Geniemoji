# OpenMoji images (Emoji 18.0)

These SVGs are the Emoji 18.0 emojis from [OpenMoji](https://openmoji.org/), the
open-source emoji and icon project, taken from
[hfg-gmuend/openmoji@2038866](https://github.com/hfg-gmuend/openmoji/tree/2038866215b0d8217cc3f62e595ddef88edf9656/color/svg).

License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

They are bundled because the latest published OpenMoji release (17.0.0) does not
include them yet; every other OpenMoji image is loaded from
`cdn.jsdelivr.net/npm/openmoji@17.0.0`. Once an OpenMoji release with Emoji 18.0 is
published, bump `OPENMOJI_VERSION` in `src/index.js` and delete this folder.
